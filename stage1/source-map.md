# 保存先と原本・複製の関係

## 公開資料

- PUB-001 → GitHub Issue #1 が参照原本。今回の工程より広い将来計画を含む。
- PUB-002 → GitHub Issue #2 が参照原本。今回の5領域の棚卸しに限定する。
- evidence/public-issues.json → 上記公開 Issue 本文の日時・ハッシュ付き固定スナップショット。原本の置換ではない。Issue #2 の修正前も別レコードで保存。
- evidence/conflicts-before.md → 前回レビュー対象 commit の conflicts.md をそのまま履歴保存した複製。

## 本人用資料

Space/Page・関連ファイルは読取のみ。本人用の新規台帳は、所有者・直接共有・継承共有・リンク共有を確認できた保存先に置く。共有設定は変更しない。詳細の所在や識別子は本人用台帳の中だけで管理し、GitHub から非公開資料へはリンクしない。

原本と複製の対応が本文に記載されていても、バイト一致や同期を推定しない。原本のハッシュを取得できた場合も、採用の証拠にはならない。原本の移動・統合・削除・上書きは行わない。

## 調査境界

検索は候補の発見であり、全件列挙や原本読了ではない。検索ツール・検索語・取得範囲・本文確認・未取得を区別して台帳に記録する。公開原本を本リポジトリへコピーできることは、非公開原本の転載許可を意味しない。

Issue #1 が列挙する他の開発リポジトリは将来の能力評価の参照候補。今回その実装・能力の再受入はしない。main に追加された別案件も変更しない。
