# Stage 3A: 汎用関節の2D干渉予備検査

これは独立した矩形の試験治具用です。既存キャラクターの形状、座標、原本、画像、外観再生成コードは含みません。元のCAD・ZIPは非公開保存のまま変更しません。

## なぜ作るか

先に原因が分からないままCAD形状を削ると、別の部品との干渉や強度不足を招きます。関節を動かしたときの**投影図上の干渉の可能性**を、再現可能な同一入力で比較するための補助検査器です。元の左腕・肩カバー・胴体の5組が解消したと判定するものではありません。

## 実行

Python 3.10以上、外部パッケージ不要。

```sh
python projects/korosuke/generic-kinematics/sweep.py projects/korosuke/generic-kinematics/example-neutral.json
python -m unittest discover -s projects/korosuke/generic-kinematics -v
```

入力は単位mm・角度deg、`joint.pivot_mm` を中心とする一軸回転、`moving` は関節ローカル座標の矩形、`fixed` はワールド座標の軸平行矩形です。`tolerance_mm` は正の安全余裕、`max_depth` / `min_interval_deg` は検証範囲の細分上限です。入力は汎用の自作例に限定してください。

| 状態 | 意味 |
|---|---|
| `PROJECTED_OVERLAP` | 実際に計測した角度で矩形の2D投影が重なった。3D衝突を確定しない |
| `PROJECTED_CLEAR` | 全角度区間で、矩形の2D投影に設定余裕以上の間隔があると保守的に確認 |
| `UNRESOLVED_2D` | 細分上限に達する等で証明できない。PASSとしない |

数値修正後は、正確な有理数の中点・周期正規化と、外向き丸めの整数区間演算を用います。共通ローカル原点で回転・外接矩形を包絡し、離隔下限と連続区間の移動上限を比較します。証明不能な区間は `UNRESOLVED_2D`、不正入力は明示拒否です。固定epsilonの追加や有限個の走査点を連続安全保証とは扱いません。許容入力、pi・三角関数の剰余境界、保証の前提、方式比較は [NUMERICS.md](NUMERICS.md) を参照してください。

`first_observed_overlap_deg_exact` が重なり証拠の正確な有理角度です。従来の数値欄は表示用のbinary64近似です。JSON小数をbinary64に読み込む際の丸めや、実測値の誤差は保証対象外です。

追加の独立高精度検証は通常実行と分離し、mpmath 1.3.0 を必要とします。再現手順と原反例は [numeric-validation](numeric-validation/README.md) に保存します。

## 制約と次の工程

- 実3Dモデルの形状・接触面積・位置誤差、関節遊び・クリアランス公差・強度・トルク・軸保持・配線・製造可能性は検証しません。
- 2D上で重なっても高さ方向に離れている場合があります。2Dで安全そうでも実CADの正確な投影かは未確認です。元の5組の干渉解除判定や機械完成認定には使えません。
- 次は**非公開原本の作業コピー**で正式CADの干渉5組を同じ角度・同じ配置・同じ形状判定器で再測定し、静的接触・動的干渉・強度・配線を区別して比較します。原本変更や公開持出しは別判断です。
- 版と検証結果を固定してから採否を決めます。CIは実際のGitHub Actions workflowがない限り成功と呼びません。
