# 現行版候補と判定基準

CURRENTは現行版である証拠が揃った場合だけ使用する。DRAFTは草案、SUPERSEDEDは置換の証拠あり、ARCHIVEDは履歴保存、CONFLICTは具体的矛盾あり、UNKNOWNは根拠不足とする。

文書の版番号・保存サービスのrevision・適用開始日を別々に管理する。更新日時が新しいことだけで正式採用としない。本文にある採用表記も、その文書の主張と外部の承認証拠を区別する。

公開資料PUB-001/PUB-002はいずれもDRAFTの計画文書。正式な行動規則ではない。私有資料の現行版候補は公開用文書では列挙しない。現行規則を変更・有効化していない。
