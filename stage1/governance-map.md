# 分類と適用状態の分離

資料分類（憲法、正式規則、運用ガイド、研究成果、草案・仮説、研究計画、辞典、原典）と、確認時点の適用状態は別欄にする。この分類は既存規則の優先関係を変更するものではない。

[ledger.schema.json](ledger.schema.json) と [台帳記入規約](ledger-format.md) は今回の公開用研究記録形式と本人用項目の対応定義。憲法や正式な運用設定ではなく、規則変更を承認するものでもない。

承認者・日時・範囲・根拠の確認と、本文の自己申告を区別する。研究成果・試験成功・ファイルの新しさを権限拡大や正式採用の証拠にしない。不明は UNKNOWN、検査していないものは NOT_TESTED。

変更対象は stage1/ の成果物、PR #3 本文・正式レビュー、Issue #2 の履歴整理に限定。README、既存原本、憲法、正式規則、運用設定、定期タスク、エージェント設定、権限、実験条件は変更しない。本人用台帳は新規作成し、元資料は編集しない。

独立レビューは最終 HEAD を再取得し、原証拠と照合する。公開側しか照合できなかった場合、非公開台帳の完全性を PASS にしない。Draft を維持し、マージや自動マージは行わない。
