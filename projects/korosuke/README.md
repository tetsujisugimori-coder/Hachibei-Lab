## 検査の区分

`verification.json` は今回回収したバイナリを実ソフトのヘッドレス処理で再読込した結果です。GUI手操作、実機、通電、製造公差、強度、全関節動作、公開権利の確証はNOT_TESTEDまたは未解決です。過去の検証記録の存在と今回の再実行は別です。

`python3 verify_archives.py <前期ZIP> <第2期ZIP>` で原ZIPと各内部ファイルをハッシュ検査できます。これはCAD形状再読込や設計成立の検査ではありません。`--self-test` は破損反例検出を確認します。

再読込はFreeCAD 1.0のopenDocument/Part.Shape.read、Blender 4.3.2のopen_mainfile/import_scene.gltfで実行。原本は保存し直さず読取。KiCad 9.0.2で前期回路原本から別出力先へnetlistを生成。再生成コードは非公開ZIPに保全し、実行する場合は原本と別ディレクトリを使ってください。

GitHub Actionsは既存mainに設定がなく、この台帳変更では新規CIを追加していません。CI成功とは報告しません。実行ログ・非公開詳細検査は原本同様別保管し、公開台帳には必要な要約のみ記録します。
