# 文書版、保存サービス revision、適用状態

文書の版番号・文書改訂日・保存サービス revision・保存サービス更新時刻・適用開始/終了日は別欄で管理する。更新日時が最新というだけでは正式採用としない。

| 適用状態 | 必要な証拠・意味 |
| --- | --- |
| CURRENT | 承認者・承認内容・適用範囲・開始日・後続の取消や置換の照合が必要。本文の自己申告だけでは不可 |
| DRAFT | 草案であることを原資料で確認 |
| SUPERSEDED | 置換対象と後継、承認・置換時点の証拠あり |
| ARCHIVED | 履歴保存である証拠あり。旧版と推測しただけでは使用しない |
| CONFLICT | 具体的矛盾を証拠で確認。未比較は NOT_TESTED |
| NOT_A_RULE | 研究計画や研究原典で、規則を制定する文書ではない |
| UNKNOWN | 適用状態を裏づける証拠不足 |

[公開索引](public-index.json) の PUB-001/PUB-002 は研究計画で NOT_A_RULE。前稿の DRAFT 表記から、文書の成熟度と規則としての適用を分けた。文書版番号・保存サービス revision は UNKNOWN のまま。Issue の更新日時を revision として埋めない。

文書本文に採用・改訂の主張がある場合は「本文記載」と「承認履歴による検証」を別にする。終期が過ぎたこと、より新しいファイルがあることだけでは、失効や置換を断定しない。非公開の候補や採用履歴は本人用台帳で確認し、公開文書には列挙しない。

今回、現行規則の変更・有効化・失効処理は行っていない。
