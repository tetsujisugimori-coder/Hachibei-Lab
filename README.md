## 共通開発方針

[工程分割・容量管理・証拠保全の共通方針](docs/common-development-policy.md)（2026-11-14版）。本人が管理する全リポジトリを対象とする。本人限定Spaceへの保存後、実ファイルを再取得し元データとのサイズ・SHA-256一致を独立照合できれば、マージ時の保全条件を満たす。Windowsへの追加移管はその必須前提としない。技術的受入とマージ実行の許可は別に確認する。

作業の入口は [AGENTS.md](AGENTS.md)。各リポジトリへの導入手順・反映状態の扱いは共通方針の第7節を参照する。
