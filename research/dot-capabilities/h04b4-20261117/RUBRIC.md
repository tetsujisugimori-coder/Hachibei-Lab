# H04-B4 採点・欠測・集計規則案 v1

本書はPLAN.mdと一体の未採用計画。実験開始BLOCKED、実原票NOT_TESTED。採点前に計画commitと正解版を凍結し、事後に条件を変更しない。

## 原応答の単位

事前登録は3応答枠のみ。B0再述はA0との一致、B1再述はA1との一致、B1改訂はA1の末尾に `改訂確認済み。` とLF1個を追加した全文との一致を評価する。B1の2枠は同一スレッド内の連続課題で、独立反復2回ではない。B0/B1の異なる原文・初期文脈・順序・質問条件を併記する。

本文は受信サービスの構造化されたassistant本文の原文字列をUTF-8として照合する。JSONの引用符・転送envelopeは本文に含めない。表示UIからの転記やコード囲み除去、前後空白のtrim、CRLF変換、Unicode正規化、大小文字変換を暗黙適用しない。原文字列が取得不能なら一致判定はMISSINGとし、見た目の一致は参考観測に留める。

|欄|値|判定|
|---|---|---|
|原票状態|COMPLETE / MISSING / NOT_TESTED|全文・順序・対象版の取得／欠測／未実施を区別|
|一致|1 / 0 / MISSING / NOT_TESTED|完全な原票が正解全バイトと一致なら1、不一致なら0|
|不明申告|YES / NO / UNKNOWN / NOT_TESTED|原応答が「不明」を明示したか。自己申告であり取得不能証明ではない|
|拒否|YES / NO / UNKNOWN / NOT_TESTED|拒否文を独立記録。原票完全なら一致0として併記|
|固有内容再現|DETECTED / NOT_DETECTED / UNKNOWN / NOT_TESTED|B0のA0全体一致またはA0に固有の連続10文字以上の一致を検出すればDETECTED。他の具体的な混入疑いもPLANの停止対象|
|送信受付|ACCEPTED / REJECTED / UNKNOWN / NOT_TESTED|API等の実受付。読取り・内容利用とは別|
|受領自己申告|YES / NO / UNKNOWN / NOT_TESTED|受信者の申告のみ。実適用認定と分離|
|取得経路・排他性・因果|UNKNOWN|一致・不明申告・受領申告から昇格させない|

B0が完全に「不明」と回答した場合は、原票COMPLETE、一致0、不明申告YESとする。「B0成功」と呼ばない。B0がA0と一致した場合は一致1だが、PLANの停止条件にも該当するためB1を開始しない。曖昧な部分再現の判断は正解管理担当と監査担当が根拠を私有票に残し、疑い未解消で進めない。未検出は混入不存在の証明ではない。

B1再述不一致だけなら改訂枠を実施可能とするが、切捨て・原票不整合・秘密露出等の停止条件は優先する。改訂の正解は直前の誤った再述ではなく、凍結済A1に指定行を追加したものとする。

## 集計と報告

固定分母は各枠1、合計3応答枠。COMPLETEで一致1、COMPLETEで一致0、MISSING、NOT_TESTEDの4区分を全枠表示する。欠測を分母から除外した一致率を主要結果にしない。全体の独立実験数は探索的1事例であり、3応答枠と実験数を同一視しない。

報告は枠ごとの一致状態と停止理由を記述する。B1再述と改訂の合算やB0との差を一般的な成功率・効果量として提示しない。「明示提供後の今回の応答は提示本文と一致した」までに限定し、Memory・自動共有・非明示取得の有無や原因を断定しない。原票欠測、内部経路、不可視初期文脈はそれぞれUNKNOWNを保持する。採点ルール改版や再試行は新しい計画版・別承認・別記録とし、旧失敗票を保持する。
