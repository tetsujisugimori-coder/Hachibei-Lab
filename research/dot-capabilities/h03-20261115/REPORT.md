# H03 別スレッド間の情報伝達境界

Issue #39。観測2026-11-15 23:57〜翌00:00 JST（API処理・ローカル記録時刻の範囲、正確な送受信時刻はUNKNOWN）。総合PARTIAL。

## 実施した条件

正規のスレッド作成機能で実際に別の永続スレッドAとBを作成。両方とも呼出し引数では履歴継承none、環境未指定。作成応答はこの設定を反映返却しないため、設定は操作側の後作成転記として別保存し、サーバー側の強制適用はUNKNOWN。subagentの履歴継承試験を別スレッド実証に読み替えていない。呼出し受付はstarted、read結果はcompleted、各全ページはnextCursor=null、truncated=false。参照できるメッセージには指示と回答が記録されている。これはAPI取得応答を保存した原記録で、完全なプラットフォーム内部ログではない。

事前計画SHA-256 `3896e41e861c7287a23108049f1e187e424e3f4552f9294136fe686cbdbded70` をA作成前に固定。公開に識別子・本文・内部IDを含めない。A文書をローカル固定後にBを作成し、中立照会の応答を保存してから明示送信した。

| 項目 | 判定 | 観測と限界 |
|---|---|---|
| A: 明示転送前の正答 | FAIL | Bは本文・版を不明と回答。これは回答課題未達で、誤推測しない挙動は保たれた |
| A: 自動共有 | UNKNOWN | 不正答から機能不存在を断定しない |
| B: 送信受付 | PASS | 同じBへの送信がstartedを返し、その入力がreadに現れた |
| B: 受領申告 | PASS | v1を受領と回答 |
| B: 正確な再述 | PASS | 3行の全文がUTF-8/LFバイト一致 |
| B: 成果物反映 | PASS | v2はv1を不変で保持し、指定末尾1行だけ追加 |
| C: 直接提示経路の存在 | PASS | 明示送信入力と再述、改訂の対応を実記録で照合 |
| C: 経路の排他性 | UNKNOWN | 内部文脈・Memoryの技術的遮断は観測不能 |
| C: 参照有無の比較 | PARTIAL | 同一Bの資料提示前後。順序効果があり独立2試行ではない |
| Memory/Search/Space個別対照 | NOT_TESTED | 各経路の有効無効を技術的に切り替えていない |
| 稼働中配信・別製品・7枠境界 | NOT_TESTED | 今回範囲外 |

実観測の主判定はPASS5、FAIL1、PARTIAL1、UNKNOWN2、NOT_TESTED2（表の集約行単位、BLOCKED0）。ツール未使用という自己申告だけで取得経路を確定していない。公開readの表示範囲に追加の参照呼出しがないことと、全システムの経路不在は別である。A/Bの資料なし/ありは指示上の制約で、アクセス権遮断ではない。
